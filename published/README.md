# published/

Qui vengono salvati i JPEG delle card pubblicate su Instagram
(`published/ANNO/MESE/AAAA-MM-GG-tipo.jpg`), committati automaticamente dal
workflow giornaliero quando `LIFEZEN_IMAGE_HOST=github`.

Instagram li scarica via **jsDelivr CDN**:

```
https://cdn.jsdelivr.net/gh/LifeZen77/Mylifezen@main/published/2026/01/2026-01-01-pensiero.jpg
```

Non cancellare i file già pubblicati: Instagram li ha referenziati e i link
vecchi smetterebbero di funzionare.
